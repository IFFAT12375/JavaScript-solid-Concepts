# JavaScript Solid Concepts

A collection of JavaScript practice exercises and small projects for learning core language concepts, data structures, browser APIs, and database basics.

This repository is for practice and experimentation. Examples may be simple, incomplete, or created to test a particular idea.

## Topics

- Variables, functions, objects, arrays, and destructuring
- Scope, closures, recursion, and constructor functions
- Data structures, including stacks, queues, and linked lists
- Array methods and number, date, and timer APIs
- DOM manipulation and browser events
- JavaScript assignments and coding exercises
- MongoDB and MySQL practice

## Repository Structure

- `*.js` - Standalone JavaScript exercises and concept examples
- `DOM/` - Small browser projects using HTML, CSS, and JavaScript
- `DB/mysql/` - MySQL practice scripts
- `DB/mongodb/` - MongoDB practice files and a sample Node.js app

## Getting Started

### Prerequisites

- Node.js
- npm
- Optional: MongoDB or MySQL for database examples

### Installation

```bash
npm install
```

## Running the Examples

Run a standalone JavaScript file with Node.js:

```bash
node functions.js
```

Replace `functions.js` with the example you want to run.

Open files inside `DOM/` in a browser to try the browser projects.
